# 📊 Mobile Sales Analysis Dashboard

## Overview

This project is an interactive Power BI dashboard built to analyze mobile sales performance across different cities, mobile models, payment methods, and customer ratings.

The dashboard provides business insights through KPIs, trend analysis, and interactive visualizations.

---

## Tools Used

- Power BI
- DAX
- Microsoft Excel

---

## Key Metrics

- Total Sales: 769M+
- Total Quantity Sold: 19K+
- Total Transactions: 4K+

---

## Dashboard Features

- Sales Analysis by City
- Daily Sales Trend Analysis
- Mobile Model Performance
- Payment Method Analysis
- Customer Rating Analysis
- Day-wise Sales Analysis
- Interactive Filters and Slicers
